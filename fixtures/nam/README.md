# NAM models for tests

Two small models from NeuralAmpModelerCore (github.com/sdatkinson/NeuralAmpModelerCore,
`example_models/`, commit 0b3d3c97b0859a3a8c92a8628c4dd89a25eb5842), MIT
licence (`LICENSE`, beside this file), by Steven Atkinson:

- `wavenet.nam`: a small WaveNet capture of a bass preamp ("Test Model");
- `lstm.nam`: a small LSTM ("Test LSTM").

The NAM plugin's tests and the contract suite run them. They are test
material, not sounds we recommend.
