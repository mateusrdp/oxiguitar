# oxiguitar-host

[OxiGuitar](https://github.com/mateusrdp/oxiguitar)'s plugin host: the user folder, settings.json, the plugin folders, reading plugins' manifests without loading them, loading plugins on first use, and choosing formats, services and tabs. Published so that the contract suite, [`oxiguitar-plugin-test`](https://crates.io/crates/oxiguitar-plugin-test), checks plugins through the same host the app uses.

Plugin authors don't depend on it directly; see [Writing OxiGuitar plugins](https://mateusrdp.github.io/oxiguitar/plugins/).
