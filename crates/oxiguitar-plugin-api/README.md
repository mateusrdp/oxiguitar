# oxiguitar-plugin-api

The [OxiGuitar](https://github.com/mateusrdp/oxiguitar) plugin interface: the C tables a plugin and OxiGuitar exchange, the messages that cross them, the manifest, the score as plugins see it, tabs, the canvas's display list and events. Plugin authors use it through the SDK, [`oxiguitar-plugin`](https://crates.io/crates/oxiguitar-plugin).

Interface 1 is frozen from OxiGuitar 0.2: later versions only add. The guide: [Writing OxiGuitar plugins](https://mateusrdp.github.io/oxiguitar/plugins/).
