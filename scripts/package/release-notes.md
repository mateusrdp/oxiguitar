## Which file do I need?

One download for your system. Each comes with the basic plugins, which open Guitar Pro files and play them.

| System | Download |
| --- | --- |
| Windows 10 and 11 (x86_64) | `OxiGuitar-@VERSION@-windows-x86_64.zip` |
| Windows on ARM | `OxiGuitar-@VERSION@-windows-arm64.zip` |
| macOS (Apple Silicon and Intel) | `OxiGuitar-@VERSION@-macos-universal.dmg` |
| Any Linux (x86_64; `aarch64` for ARM) | `OxiGuitar-@VERSION@-x86_64.AppImage`, for Wayland and X11 desktops alike |
| Debian, Ubuntu (x86_64; `arm64` for ARM) | `oxiguitar_@VERSION@_amd64.deb` with `oxiguitar-plugins-basic_@VERSION@_amd64.deb`, installed together |
| Fedora (x86_64; `aarch64` for ARM) | `oxiguitar-@VERSION@-1.x86_64.rpm` with `oxiguitar-plugins-basic-@VERSION@-1.x86_64.rpm`, installed together |

The .deb and .rpm above are the Wayland build; a Linux desktop without Wayland takes the files named `oxiguitar-x11` instead, with the same plugins' package. [Installing](https://mateusrdp.github.io/oxiguitar/installing.html) explains each step, and SHA256SUMS holds every file's checksum.
