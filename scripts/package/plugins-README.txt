OxiGuitar basic plugins
=======================

These are the plugins the OxiGuitar project writes and recommends: one for
each Guitar Pro format (Guitar Pro 3, 4, 5, 6 and 7-8), the SoundFont
player, which plays the tracks with a sound set (SoundFont or SFZ), and the
ones that play sound through your system (PipeWire and ALSA on Linux).
OxiGuitar alone opens and plays nothing; it finds these in
/usr/lib/oxiguitar/plugins.

Help -> About lists every plugin folder OxiGuitar searches, and
Tools -> Plugins lists the plugins it found. More:
https://mateusrdp.github.io/oxiguitar/plugins.html

The plugins are free software under the GNU GPL, version 3 or later, like
OxiGuitar itself: https://github.com/mateusrdp/oxiguitar
