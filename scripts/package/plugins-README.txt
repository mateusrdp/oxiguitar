OxiGuitar basic plugins
=======================

These are the plugins the OxiGuitar project writes and recommends: one for
each Guitar Pro format (Guitar Pro 3, 4, 5, 6 and 7-8). OxiGuitar alone
opens no file; with these it opens Guitar Pro files.

Put the .oxp files in a plugin folder, then start OxiGuitar again:

  Linux    ~/.local/share/oxiguitar/plugins/
  macOS    ~/Library/Application Support/OxiGuitar/plugins/
  Windows  %APPDATA%\OxiGuitar\plugins\
           or the plugins folder beside oxiguitar.exe

OxiGuitar creates your own plugin folder the first time it starts. Help ->
About lists every plugin folder it searches, and Tools -> Plugins lists the
plugins it found. More: https://mateusrdp.github.io/oxiguitar/plugins.html
