# Cabinet impulse responses shipped with the NAM plugin

Four impulse responses from the **BestPlugins Mega Pack 2** by David Fau
Casquel (2013), as Guitarix ships them
(github.com/brummer10/guitarix, `trunk/IR/BestPlugins_Amps/`), under the GNU
General Public License, version 2 or later (`LICENSE`, beside this file).
Only the file names changed (lowercase, without spaces):

| File | Guitarix's name |
| --- | --- |
| `mesa-boogie-mark-v.wav` | `Mesa Boogie Mark V.wav` |
| `marshall-jmp-2203-mod.wav` | `Marshall JMP 2203  Jose Arredondo mod.wav` |
| `evh-5150-iii.wav` | `EVH 5150 III.wav` |
| `engl-retro-tube.wav` | `Engl Retro Tube.wav` |

Each is mono, 24-bit, 44.1 kHz, 75 to 125 ms long. The plugin builds them
into `nam.oxp` and converts them to the playback rate when a track is
prepared. The names are those of the amplifiers the pack's author made the
responses to sound like; the makers have nothing to do with them.
