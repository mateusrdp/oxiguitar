# Tracks and notation

The track list along the bottom of the window shows every track of the song: its number, its name, its strings (or Drums) and its notation buttons. **View → Tracks** (F8) hides or shows the list; drag its top edge to make it taller or shorter.

- **Click a name** to show that track alone.
- **Click a hidden track's notation button** to show it with the others, lined up bar by bar in one score.
- **View → Multitrack** is ticked whenever more than one track is shown. Choosing it goes back to the first of those tracks, or, with one track shown, shows them all.
- With several tracks, each system starts with the tracks' names.

## Notation buttons

Each track has two buttons: a **treble clef** for standard notation and **TAB** for tablature. A lit button is on. Tracks without strings, such as drums, have only the clef.

| Clef | TAB | The track shows |
| --- | --- | --- |
| on | on | standard notation above tablature |
| on | off | standard notation |
| off | on | tablature, with the rhythm drawn around it |
| off | off | nothing: the track is hidden |

Clicking either button of a hidden track shows it again, with that notation. The last track shown cannot be hidden.

When a file opens, each track shows the notation it was saved with. Tablature is on only for fretted instruments (guitars, basses, banjo and the like), and keyboard tracks get a grand staff, split between the hands.
