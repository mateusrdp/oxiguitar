# Dark page and dynamics

**View → Dark Page** shows light notation on a dark page, which is easier on the eyes at night. It changes only the screen: a PDF is always printed on a light page.

**View → Dynamics** shows or hides dynamics markings such as *mf* and *pp* (shown by default). Some files have so many that they clutter the page. Guitar Pro 3 to 5 files store loudness per note rather than as markings, so they never show any.
