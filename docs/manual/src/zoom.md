# Zoom

OxiGuitar has two zooms.

**Score zoom** enlarges the score only, from 25 % to 400 %, with the slider in the bottom-right corner of the score. 100 % is in the middle of the slider and the knob snaps to it. Click the percentage to go back to 100 %. The middle of the view stays in place as you zoom.

**Interface zoom** enlarges the whole window, menus and track list included. It has no control on screen:

| Keys | Interface zoom |
| --- | --- |
| Ctrl + mouse wheel | in or out |
| Ctrl + + (or Ctrl + =) | in |
| Ctrl + − | out |
| Ctrl + 0 | back to 100 % |

The keypad's +, − and 0 work too. The steps are those of a web browser, from 50 % to 200 %, on top of your system's own display scaling.
