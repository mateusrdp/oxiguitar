# Layouts

**View → Layout** chooses how the staves are laid out, as in Guitar Pro 8:

| OxiGuitar | Guitar Pro 8 | What you see |
| --- | --- | --- |
| **Page** | Page – Vertical | Pages, with systems filling the page width and breaking into pages, as the PDF prints them |
| **Vertical** | Screen – Vertical | Systems as wide as the window, one under the other, without pages; zooming or resizing the window reflows the bars |
| **Horizontal** | Screen – Horizontal | The whole song on one long line, scrolling sideways |
| **Parchment** | Page – Scroll | Systems as wide as the page, in one long column without page breaks |

Scroll with the mouse wheel, the arrow keys, Page Up and Page Down, Space, Home and End. In the Horizontal layout the wheel scrolls along the line when the line fits the window's height.
