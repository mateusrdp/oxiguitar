# Plugin manuals

OxiGuitar opens, plays and exports files only through plugins ([Settings and plugins](plugins.md)). The program's own download holds none of them, so each one has its own manual, which says what it does, how to use it and what it needs.

This work depends on the [packages manual](https://mateusrdp.github.io/oxiguitar-packages/manual/). It lists every official plugin with a link to its manual, and says how to install them.

To open and play a score you need at least a plugin that reads Guitar Pro files, one that plays a score and one that sends the sound to your speakers. If one is missing, OxiGuitar tells you once, and you can silence the message ([Advice dialogs](plugins.md#advice-dialogs)).

## Plugins from elsewhere

Anyone can write a plugin ([the plugin developer guide](plugin-guide/index.html)). A plugin is a file ending in `.oxp`; put it in your plugins folder and it is found at the next start. We make no promises about plugins from anywhere else, so install only plugins you trust.
