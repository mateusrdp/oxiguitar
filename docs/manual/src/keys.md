# Keyboard and mouse

**Help → Keyboard and Mouse** (F1) shows this list in the program. On macOS, use ⌘ where it says Ctrl.

| Keys and mouse | Does |
| --- | --- |
| Ctrl + O | Open a file |
| Ctrl + Q | Quit |
| F1 | Keyboard and mouse help |
| F8 | Show or hide the track list |
| Mouse wheel | Scroll the score (along the line in the Horizontal layout) |
| Arrow keys, Page Up, Page Down, Space | Scroll the score |
| Home, End | Go to the start or the end of the score |
| Ctrl + mouse wheel | Zoom the interface in or out |
| Ctrl + + / Ctrl + − / Ctrl + 0 | Zoom the interface in, out, back to 100 % |
| Score zoom slider, bottom right | Zoom the score; click the percentage for 100 % |
| Click a track's name | Show that track alone |
| Tick a track | Show it with the others |
| Click the status line | Close the message |
| Escape, or a click anywhere | Close Keyboard and Mouse or About |
