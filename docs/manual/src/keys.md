# Keyboard and mouse

**Help → Keyboard and Mouse** (F1) shows this list in the program. On macOS, use ⌘ where it says Ctrl.

| Keys and mouse | Does |
| --- | --- |
| Ctrl + N | A new score |
| Ctrl + O | Open a file |
| Ctrl + S / Ctrl + Shift + S | Save / save as another file ([Saving files](saving.md)) |
| Drop a file on the window | Open it (not on Wayland) |
| Ctrl + Q | Quit (asking first about changes not saved) |
| F1 | Keyboard and mouse help |
| F7 / F8 | Show or hide the left / bottom panel (View → Panels) |
| Mouse wheel over the score | Scroll the score (along the line in the Horizontal layout) |
| Shift + mouse wheel over the score | Zoom the score, around the pointer |
| Page Up, Page Down, the scroll bars | Scroll the score (Space and the arrow keys too, with no score open) |
| Space | Play from the caret, or pause ([Playing a score](playback.md)) |
| Ctrl + Left / Ctrl + Right | A bar back or on: the sound while it plays, else the caret |
| Click in the music | Put the caret there; Shift + click selects up to it |
| Arrow keys, Home, End, Tab, Ctrl + Up / Down, Ctrl + 1 to 4 | Move the caret ([Editing](editing.md)) |
| Shift + those keys, Ctrl + Shift + Left / Right | Select |
| Ctrl + A / Escape | Select everything / drop the selection |
| 0 to 9, Enter, R, − / +, Shift + . / Ctrl + ., L / Shift + L, Backspace, Shift + Delete, Ctrl + Shift + Delete, Ctrl + Insert, Alt + arrows, Alt + 1 to 4, / | Enter notes ([Entering notes](editing.md#entering-notes)) |
| Insert, Ctrl + Delete, [ and ], \| | Insert and delete bars, repeats, free time ([Bars](editing.md#bars)) |
| Ctrl + K, Ctrl + /, D, Shift + Insert | The Bar dialog ([Bars](editing.md#bars)) |
| X, O, ;, :, !, H, (, S, Alt + S, Shift + S, V, P, Shift + P, I, Y, Ctrl + Alt + Y, Alt + P, Alt + T, N, ", T, ), $, <, G, Ctrl + Alt + G, Ctrl + D, Ctrl + U, Shift + D, Shift + U, Ctrl + Alt + W | Effects ([Effects](editing.md#effects)) |
| B / Ctrl + Alt + V | The bend editor / the whammy bar's ([Bends and the whammy bar](editing.md#bends-and-the-whammy-bar)) |
| A / Shift + T | The chord dialog / the beat's text ([Chords, text and lyrics](editing.md#chords-text-and-lyrics)) |
| Ctrl + T, then Space, −, Backspace, Up / Down, Enter | Type lyrics on the page ([Chords, text and lyrics](editing.md#chords-text-and-lyrics)) |
| Ctrl + C, Ctrl + X, Ctrl + V, Ctrl + Shift + V | Copy, cut, paste, Special Paste ([Copy, cut and paste](editing.md#copy-cut-and-paste)) |
| Ctrl + Z / Ctrl + Y | Undo / redo |
| F4 | The next bar that doesn't add up |
| Ctrl + F | Search the palette; Escape empties it, Enter goes back to the score |
| Ctrl + mouse wheel | Zoom the interface in or out |
| Ctrl + + / Ctrl + − / Ctrl + 0 | Zoom the interface in, out, back to 100 % |
| Score zoom slider, bottom right | Zoom the score; click the percentage for 100 % |
| Click a track's name | Select that track (left-click shows only it; Shift-click toggles it in multitrack) |
| Click a track's overview | Move the playback (or the caret) there |
| Click a hidden track's clef or TAB | Show it with the others |
| Click a panel's open tab, or its chevron | Fold the panel away or open it again |
| Click the line at the bottom | See every message; its chevron folds it back |
| Escape, or a click anywhere | Close Keyboard and Mouse or About |
