# Features and their tests

Everything OxiGuitar itself does (the viewer, the editor, the player, the plugin host and the command-line program), and the tests that check it. The test names are the ones `cargo test` prints, after the crate (`oxiguitar-edit/lib::...` is a test inside `oxiguitar-edit`; `oxiguitar-app/oxiguitar::...` one inside the app); a `stage:` is a step of `scripts/test-all.py`. The script fails when a feature here names no test, or names a test that doesn't exist, so a new feature gets its row and its tests in the same pull request (the [Testing](testing.md) page says how to run them, on your own files too).

What the plugins do is on each plugin's own Features page: OxiGuitar opens no file format and plays no sound by itself. The tests that need a file format use the released Guitar Pro plugins.
